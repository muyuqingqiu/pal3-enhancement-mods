# 仙剑三 PC 功能模组

为 Steam 版《仙剑奇侠传三》提供手柄操作、自由视角和经验倍率设置。基于 PAL3patch v5.1 的插件接口，三个模组可分别安装、启用与卸载。

[下载发行包](https://github.com/muyuqingqiu/pal3-enhancement-mods/releases) · [安装与操作](文档/安装与操作.md) · [构建与发布](文档/构建与发布.md) · [第三方说明](文档/第三方说明.md)

> **v0.3.0 为 PC 预发布版本。** 已验证插件构建、独立安装与卸载，以及 PC 标题、读档和菜单代表流程。完整剧情、各种实体手柄与长期游玩稳定性仍需更多测试。

## 三个模组

| 模组 | 主要功能 | 发行文件 |
|---|---|---|
| 手柄 | 摇杆移动、走跑切换、条件跳跃、加速移动、菜单与战斗导航、NPC 交互 | `PAL3-Controller-0.3.0.zip` |
| 视角 | 右摇杆旋转、俯仰、远近调节、第一人称与镜头重置 | `PAL3-Camera-0.3.0.zip` |
| 金手指 | 人物经验与技能熟练度倍率，分别设置并保存，默认 1 倍 | `PAL3-Cheats-0.3.0.zip` |

不启用金手指时，系统菜单不显示金手指入口提示，经验倍率保持 1 倍。

三个模组共用 `PAL3Gamepad.dll`，通过各自的开关文件启用。安装器记录共用文件的使用者，卸载其中一项时保留其他模组仍在使用的文件。游戏启动后由 PAL3patch 加载插件，不需要运行打包工具。

## 开始使用

1. 准备正版 Steam 版《仙剑奇侠传三》，安装 [PAL3patch v5.1](https://github.com/zhangboyang/PAL3patch/releases/tag/v5.1)，确认游戏能够正常启动。
2. 安装 Python 3.11 或以上版本，关闭游戏，下载所需模组 ZIP 并解压。
3. 双击解压目录中的 `安装.cmd`，输入包含 `PAL3.exe` 的游戏目录。
4. 手柄或视角模组按[安装与操作](文档/安装与操作.md)生成本地地图查询数据；只用金手指时无需该步骤。
5. 启动游戏。需要移除模组时，关闭游戏后运行对应的 `卸载.cmd`。

默认采用任天堂实体按键位置，Xbox 手柄上的字母与游戏提示不同，请先查看[按键对照](文档/安装与操作.md#按键对照)。

## 支持范围

- Windows 上已核验的 Steam 中文版，游戏程序显示 `V1.04`，PAL3patch v5.1。
- 使用 XInput 接口的手柄；其他设备需要自行提供合适的 XInput 映射。
- 安装器核对程序文件哈希，不覆盖存档、截图和个人设置。
- 不支持《问情篇》、其他补丁组合或不同程序版本的直接套用；代码包含固定程序地址，版本不匹配可能导致崩溃。
- 本仓库和发行附件不包含原版游戏、游戏场景、地图查询成品、字体、第三方运行库或高清素材。NS 发行包不在本次发布范围。

## 源码结构

```text
源码/           手柄、菜单、场景、战斗、视角、经验倍率和定向验证
脚本/           构建、打包、安装和本地地图数据生成
文档/           安装、开发、第三方依赖和发布说明
兼容版本.json   已验证的程序文件哈希
地图数据依赖.txt 本地地图生成所需的 Python 依赖
```

维护者的图形打包工具不随玩家发行包提供。源码仓库保留命令行构建入口，供开发者重建插件和生成对应模组包。
