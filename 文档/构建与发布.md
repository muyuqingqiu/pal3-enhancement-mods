# 构建与发布

## 构建条件

使用 Windows、Python 3.11 或以上版本和 Zig 0.17.0。编译目标固定为 `x86-windows-gnu`，生成 PAL3patch v5.1 可加载的 32 位插件。

从 PAL3patch 作者仓库取得 SDK，固定到 v5.1 对应提交：

```text
git clone https://github.com/zhangboyang/PAL3patch.git .依赖/PAL3patch
git -C .依赖/PAL3patch checkout f0a2847b1e175c5801021dd8c1704b265f111e12
```

该目录只用于本地构建，不提交到仓库。

## 编译、检查和打包

```text
py -3 -B 脚本/构建与打包.py --zig "D:\工具\zig\zig.exe" --sdk ".依赖/PAL3patch/src/PAL3patch/include" --版本 0.3.0 --检查
```

一次编译插件，运行输入、场景、功能开关与安装器的定向检查，再制作三个 PC 模组包。只需打某几项时追加 `--模组 手柄 视角` 等参数。

输出目录：

- `构建产物`：DLL、导入库、检查程序、编译缓存和构建信息。
- `发行产物/版本号`：三个所选 ZIP、`SHA256.txt` 和 `BUILD-MANIFEST.json`。

版本号使用三段数字，每次正式发包提高版本。同一批附件共用一次编译的 DLL。构建信息记录编译器版本、SDK 主头文件哈希、源码哈希和是否执行定向检查；编译时间可能使二进制哈希不同，不承诺不同机器得到完全相同的 DLL 字节。

## 模组文件

每份发行包仅有三项需要写入游戏目录的文件：共用 `plugins/PAL3Gamepad.dll`、共用 `mods/pal3/modular.enabled` 和自身的功能开关。其他内容为安装器、说明及本地地图数据生成脚本。

| 模组 | 独有开关 |
|---|---|
| 手柄 | `mods/pal3/controller.enabled` |
| 视角 | `mods/pal3/camera.enabled` |
| 金手指 | `mods/pal3/cheats.enabled` |

游戏只在启动时读取开关。安装器使用所有者记录保护共用文件，维护新功能时应保持该行为。

## 发布步骤

1. 在独立源码目录完成构建和定向检查，确认三个 ZIP 的插件哈希一致。
2. 在测试副本检查单项安装、组合安装、单项卸载、全部恢复和存档保护。
3. 检查 ZIP 只包含自己的插件、开关、安装器和说明，不能带入原版文件、SDK、字体、地图数据或高清素材。
4. 为对应源码提交创建版本标签，将 PC ZIP、`SHA256.txt` 与 `BUILD-MANIFEST.json` 作为 GitHub Release 附件。附件文件名使用 ASCII，避免上传服务改写中文名称。
5. 核对远端附件数量、大小和下载哈希。仍有实际游玩待验证项时标记为预发布，并在说明中列明测试范围。

图形打包工具用于维护者本地，不作为玩家运行或工坊发布内容。此流程不发布 NS 包。
