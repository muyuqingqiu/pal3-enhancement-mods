仙剑奇侠传三 PC 功能模组 v0.3.0，基于 PAL3patch v5.1，提供三个可独立安装、启用和卸载的模组。

| 附件 | 内容 |
|---|---|
| `PAL3-Controller-0.3.0.zip` | 手柄移动、菜单与战斗导航、条件跳跃和基础交互 |
| `PAL3-Camera-0.3.0.zip` | 镜头水平旋转、俯仰、远近、第一人称与重置 |
| `PAL3-Cheats-0.3.0.zip` | 人物经验与技能熟练度倍率，未启用时无系统提示 |
| `SHA256.txt` | 三个 ZIP 的 SHA-256 |
| `BUILD-MANIFEST.json` | 插件、源码和附件的构建与文件记录 |

下载所需 ZIP 并解压，关闭游戏，运行其中的 `安装.cmd`。需要正版 Steam 中文版 V1.04、PAL3patch v5.1 和 Python 3.11 或以上版本。手柄与视角需要按说明从本机游戏生成地图查询数据，只生成一次即可共用；金手指无需此步骤。

默认采用任天堂按键位置：Xbox 字母 B 对应确认，A 对应返回，Y 对应提示中的 X，X 对应提示中的 Y。详见[安装与操作](https://github.com/muyuqingqiu/pal3-enhancement-mods/blob/main/文档/安装与操作.md)。

本版本标记为 **PC 预发布**。源码构建、定向检查、安装与恢复、PC 标题、读档和菜单代表流程已验证；完整剧情、不同实体手柄和长期游玩稳定性仍需进一步反馈。

附件不包含游戏、场景、地图几何成品、第三方补丁、字体、高清素材或 NS 包。图形打包工具不随模组分发，NS 成品不在此次发行范围。
