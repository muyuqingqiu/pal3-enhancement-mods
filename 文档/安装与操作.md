# 安装与操作

## 运行条件

需要已核验的 Steam 中文版《仙剑奇侠传三》V1.04、PAL3patch v5.1、Python 3.11 或以上版本。PAL3patch 从[作者发布页](https://github.com/zhangboyang/PAL3patch/releases/tag/v5.1)取得，选择仙剑三的 `PAL3patch`，不要选择《问情篇》的 `PAL3Apatch`。发行包不附带游戏或外部补丁。

## 安装和卸载

关闭游戏后，将所需模组解压到任意下载目录，双击 `安装.cmd`，输入包含 `PAL3.exe` 的游戏目录。不同模组可从各自解压目录安装到同一个游戏目录。

安装器会核对 `PAL3.exe`、`gbengine.dll` 和 `PAL3patch.dll`，拒绝不匹配的版本。安装前文件和模组记录保存在游戏目录的 `.仙剑增强模组` 中，请保留至卸载完成。游戏运行期间不执行安装或卸载。

双击对应包的 `核验.cmd` 检查安装文件；使用 `卸载.cmd` 只移除该模组。最后一个使用者卸载后才恢复或删除共用 DLL。存档、截图、个人设置和本地生成的地图数据不参与安装与卸载。用户自行修改过的安装文件会使卸载停止，避免覆盖未知改动。

升级时使用所需的新发行包重新安装，不要用旧包覆盖新插件。不要混用本安装器与手动复制、其他模组管理器对同一 DLL 的覆盖操作。

## 生成地图查询数据

手柄的附近 NPC 判断和视角的地图范围计算使用 `.p3cm` 查询数据。这些数据从玩家自己的场景包中读取并在本地生成，不随模组分发。

在模组解压目录打开命令行，安装依赖后运行 `生成地图数据.cmd`：

```text
py -3 -m pip install -r 地图数据依赖.txt
```

输入游戏目录，等待生成完成。输出位于游戏目录的 `hd/camera`，脚本只读取 `scene/*.cpk`，不修改场景包或存档。两个模组共用同一份查询数据，只需生成一次。只安装金手指时无需生成地图数据。

命令行也可指定独立输出目录：

```text
py -3 -B 生成地图查询数据.py --游戏目录 "D:\游戏\PAL3" --输出 "D:\地图数据"
```

自定义输出用于开发检查；游戏实际读取的目录仍为 `hd/camera`。

## 按键对照

默认按任天堂实体按键位置处理。普通 Xbox 布局对应如下：

| 游戏提示 | 任天堂位置 | Xbox / XInput 字母 |
|---|---|---|
| A 确认／交互 | 右侧 | B |
| B 返回／条件跳跃 | 下方 | A |
| X 切换存读等 | 上方 | Y |
| Y 金手指 | 左侧 | X |
| Plus 打开菜单 | Plus | Menu / Start |

| 场景 | 操作 |
|---|---|
| 自由探索 | 左摇杆移动；按下左摇杆切换默认走路／跑步 |
| 可跳跃位置 | B 请求原版跳跃，落点仍受游戏规则限制 |
| 不可跳跃位置 | 按住 B 使用 2 倍跑速，剧情接管时不加速 |
| 自由镜头 | 右摇杆水平与上下调整；按住 R，上下推右摇杆调整远近 |
| 镜头重置 | 按下右摇杆，恢复默认俯视并对齐人物方向 |
| 菜单与列表 | 方向键／左摇杆选择，支持长按连续；右摇杆滚动支持的列表 |
| 系统页 | X 切换存储／读取；启用金手指时 Y 打开倍率页 |
| 金手指页 | 上下选择，左右调整，B 返回；也支持键盘 Y 与鼠标按钮 |
| 战斗 | 方向键／摇杆选择命令和目标，B 返回；R 调用原版重复上次操作 |
| 鼠标模式 | 允许的场景中按住 L，右摇杆移动鼠标；系统页与战斗 L/R 操作期间禁用 |

视角模组单独启用时只接管镜头相关输入；手柄模组单独启用时不改变自由视角。金手指页的人物与技能倍率独立保存，未启用金手指时两项均按 1 倍处理。

## 测试范围与限制

v0.3.0 为 PC 预发布版本。已执行正式构建、功能组合和安装器定向检查，以及 PC 标题、读档和系统菜单代表流程。完整剧情、所有场景和各种实体手柄仍需实际游玩验证。

镜头允许较大范围调整，原版场景中未设计给玩家观看的区域可能出现缺面、黑色远景或遮挡。该发行包不添加天空或修改模型，也不启用整组遮挡透明化。

发现异常时，关闭游戏后卸载对应模组，再核对原版与 PAL3patch 是否正常运行。反馈请附场景、步骤、启用模组及 `PAL3patch.plugin_log.txt` 中相关记录。
