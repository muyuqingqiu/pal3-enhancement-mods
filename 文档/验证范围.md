# v0.3.0 验证范围

验证日期：2026 年 10 月 28 日。适用环境为 Windows、Steam 中文版《仙剑奇侠传三》V1.04 和 PAL3patch v5.1。

## 已完成检查

| 项目 | 验证结果 |
|---|---|
| 独立源码构建 | 使用固定 PAL3patch v5.1 源码头文件和 Zig 0.17.0，生成 32 位功能插件 |
| 功能范围 | 不编译高清加载代码，不附带第三方运行文件、字体或游戏素材 |
| 输入与场景逻辑 | 输入边沿、灵敏度、取消处理和场景输入定向检查通过 |
| 功能开关 | 八种组合通过；未启用金手指时提示关闭，人物与技能倍率为 1 |
| 安装器 | 八项定向测试通过，包含解压目录安装、组合卸载、共用文件升级及原文件保护 |
| 三个发行 ZIP | 实际解压并组合安装通过，共有五个游戏目标文件 |
| 单项卸载 | 卸载手柄与视角后保留金手指，共有三个目标文件，核验通过 |
| 游戏加载 | 公开插件初始化成功；只启用金手指时 controller=0、camera=0、cheats=1 |
| PC 代表流程 | 标题、十号客栈存档读取、原版菜单、系统页、键盘 Y 打开和关闭金手指页面通过 |
| 地图生成 | 从本地原版场景生成 335 份查询数据，未改写原版场景包 |
| 恢复与存档 | 全部卸载后原测试插件恢复，六份既有测试存档哈希一致 |

## 仍需实际游玩验证

- 不同型号实体手柄及其 XInput 映射。
- 完整剧情、所有战斗类型和后期场景。
- 所有场景下的自由镜头、第一人称、遮挡和远近边界。
- 长时间游玩、频繁切场景和第三方补丁组合。

本版本标记为 PC 预发布。定向检查和代表流程通过不等同于完整游戏验收。NS 包与高清素材不在此次发布范围。
