# 贡献指南

## 修改范围

本仓库维护 PC 手柄、视角和经验倍率功能。提交前说明具体触发条件、预期变化和验证方法，避免把不相关功能或原版素材混入同一改动。

游戏与 PAL3patch 版本由 `兼容版本.json` 和 SDK 固定提交约束。修改程序地址、结构体读取或调用签名时，应先确认真实程序对应关系，再进行定向验证。

## 验证要求

- 使用“构建与打包”入口完成编译及相关定向检查。
- 修改功能开关时，检查未启用功能不会接管输入、显示入口或改变经验倍率。
- 修改安装器时，检查共用文件、未知修改保护、逐项卸载和存档保护。
- 修改输入逻辑时，记录发出的输入与实际界面或场景变化；命令执行成功不能代替游戏接收成功。
- 实体手柄与完整游戏流程尚未验证的内容应明确说明。

## 提交与反馈

提交信息使用中文，说明解决了什么问题。PR 描述包含问题、行为变化和验证结果。不要提交游戏、存档、生成后的地图数据、第三方依赖、缓存或二进制发行文件；成品通过 Release 附件提供。

报告问题时提供游戏版本、PAL3patch 版本、模组组合、手柄型号和简短复现步骤。涉及固定程序地址的崩溃可附相关日志；不要上传完整游戏安装目录。
